# Bridge

Рабочее название. Объединяет устройства одной сети (ПК, ноутбук, телефон) в одно рабочее место:
общий курсор и клавиатура, перетаскивание файлов курсором между устройствами, общий буфер обмена,
проброс MIDI. Платформы: Windows 10/11, macOS 13+, Linux (X11, Wayland), Android 10+.

**Статус:** этап 1. Готовы:

- веха 0 — каркас и CI;
- веха 1 — протокол;
- веха 2 — ядро, QUIC-транспорт с закреплением сертификатов, демон `bridged`, локальный IPC и CLI `bridge`;
- веха 3 — обнаружение (mDNS, ручной IP) и сопряжение по коду или QR, права устройств, отзыв.

Устройства находят друг друга, сопрягаются и держат зашифрованное соединение с переподключением.
Общего курсора, буфера, файлов и MIDI пока нет.

## Попробовать на двух устройствах

На каждом устройстве запустите демон:

```bash
bridged
```

На первом устройстве откройте сопряжение — появятся код и QR-код:

```bash
bridge pair --show
```

На втором устройстве посмотрите найденные устройства и введите код:

```bash
bridge nearby
```

```bash
bridge pair <начало отпечатка> <код>
```

Если mDNS в сети не работает, укажите адрес: `bridge pair 192.168.1.20:47800 <код>`.
После сопряжения устройства соединяются сами, в том числе после перезапуска (`bridge devices`, `bridge status`).

## Сборка

Нужен `rustup`; версия toolchain закреплена в `rust-toolchain.toml` и ставится автоматически.

```bash
cargo build --workspace
```

Проверки, которые выполняет CI:

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
cargo xtask check-deps
cargo deny check
```
