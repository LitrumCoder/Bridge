# Ограничения платформ

Черновик по результатам исследования (2026-10-26). Пункты подтверждаются или уточняются на соответствующих вехах.

| Платформа | Ограничение | Причина | Что делаем / варианты |
|---|---|---|---|
| Windows | Нельзя управлять окнами с повышенными правами, UAC-диалогами, экраном блокировки | UIPI: `SendInput` молча не доставляет ввод в процессы с более высоким уровнем целостности | Сообщение в UI при попадании на такое окно; позже — опциональная служба SYSTEM (ROADMAP) |
| Windows | Хук может быть снят системой без уведомления | `LowLevelHooksTimeout` (≤ 1000 мс с Win10 1709) | Обработчик хука не блокируется и только спрашивает маршрутизатор; хуки переустанавливаются раз в 60 с |
| Windows | Пока курсор на другом устройстве, системный курсор A виден в центре основного монитора | Скрыть курсор для чужих приложений можно только через `SetSystemCursor`, а он оставит курсор невидимым после аварийного завершения | Оставлено видимым ради безопасности; вариант — оверлей-маска (веха 9) |
| Windows | Физический размер мониторов оценивается по DPI, а не по EDID | Чтение EDID из реестра не реализовано на этапе 1 | Редактор раскладки (веха 9) позволяет поправить размер; EDID — в ROADMAP |
| Windows | Переход через край при упоре курсора в край экрана зависит от того, сообщает ли хук координату за пределами экрана | Документация `MSLLHOOKSTRUCT` этого явно не описывает | Ручная проверка I1 на реальной машине; при необходимости — Raw Input для дельт |
| Linux X11 | В локальном режиме события нельзя «проглотить», только наблюдать | В X11 нет системных хуков; есть только активный захват (grab) | Переход определяется по raw-дельтам, после него включается `XGrabPointer`/`XGrabKeyboard` |
| Linux X11 | Синхронизация раскладки и ввод текста с телефона пока не поддерживаются | Нужны XKB-группы и временная перепривязка keysym | `PlatformError::Unsupported`; TODO в коде, ROADMAP |
| Linux X11 | События от XTest-устройств игнорируются при захвате | Так мы отличаем собственную инъекцию от ввода пользователя; xdotool и аналоги тоже не перехватываются | Осознанный компромисс |
| Windows 10 / 11 до 25H2 | Нет встроенных виртуальных MIDI-портов | Windows MIDI Services API — только Windows 11 25H2+ | Режим loopMIDI (ставит пользователь, мы не распространяем) |
| Windows 11 25H2+ | Видимость виртуальных устройств WMS для старых DAW не подтверждена | Документация не говорит явно | Spike на вехе MIDI, затем уточнение |
| macOS | Нужно разрешение Accessibility; App Store невозможен | Активный `CGEventTap` и `CGEventPost` требуют Accessibility, песочница их не допускает | Онбординг с проверкой и кнопкой открытия настроек; распространение вне App Store с нотаризацией |
| macOS | Ввод не перехватывается в полях паролей | Secure Event Input | Это защита ОС, обхода нет; в UI — подсказка |
| macOS | Поведение DAW с file promises не документировано | — | Также отдаём file URL на staging; ручные тесты Logic/Ableton |
| macOS | Бэкенд ввода собран только `cargo check`/clippy под `aarch64-apple-darwin`, на настоящем Mac не запускался | У разработчика нет Mac | Юнит-тесты — в CI `macos-latest`; ручные проверки I1–I12 выполняет владелец |
| macOS | Синхронизация раскладки не поддерживается | Text Input Sources (`TISSelectInputSource`) не подключены на этапе 1 | `Unsupported` при переключении; TODO(M4c+) |
| macOS | Программное включение Caps Lock срабатывает не на всех версиях | Синтетическое нажатие Caps Lock система иногда игнорирует; надёжный путь — IOKit `IOHIDSetModifierLockState` | Шлём нажатие Caps Lock; при сбое состояние Caps может разойтись |
| macOS | Пока курсор на другом устройстве, курсор Mac виден на месте ухода | `CGDisplayHideCursor` работает только для активного приложения | Как на Windows: оверлей-маска — веха 9 |
| Linux Wayland | Бэкенд (InputCapture, RemoteDesktop, EIS) не проверен на настоящем композиторе | В WSL и CI нет GNOME/KDE с порталами | Ручная проверка I13; CI с композитором — ROADMAP |
| Linux Wayland | Синхронизация раскладки и Lock-клавиш недоступна | Порталы не сообщают и не меняют раскладку | `Unsupported`; TODO(M4c+) |
| Linux Wayland | Если пользователь прервал захват клавишей композитора, роутер считает, что курсор ещё на другом устройстве | Сигнал `Deactivated` приходит без координаты, а синтетического возврата в роутере нет | Аварийный хоткей Ctrl+Alt+Shift+Esc возвращает управление |
| Linux Wayland | Общий курсор только на GNOME 46+ и KDE Plasma 6.1+ | Портал InputCapture не реализован в Sway, Hyprland, COSMIC, niri | Честное сообщение в журнале; с RemoteDesktop устройство остаётся «только приёмником». Режим переключения по хоткею — веха 9 (нужно окно в фокусе) |
| Linux Wayland | Диалог разрешения может появляться при каждом запуске | Не все реализации сохраняют restore token InputCapture | Используем restore token, где есть |
| Linux Wayland | Нет бесшовного drag&drop с другого устройства | Нельзя инъектировать drag между клиентами | Сохранение в выбранную папку + уведомление |
| Linux Wayland | Буфер обмена на чистом Wayland не синхронизируется (этап 1) | Нужен `ext-data-control`/`wlr-data-control`, клиент не написан | `Unsupported`, TODO(M5+); с XWayland работает X11-путь, но видит буфер только при фокусе X-клиента |
| Windows | Содержимое с другого устройства не попадает в журнал буфера (Win+V) и облачный буфер | Иначе журнал сразу запрашивает все форматы, и ленивая выдача теряет смысл | Помечаем объявление `CanIncludeInClipboardHistory=0` |
| Windows | Сторонние мониторы буфера могут сразу прочитать текст с другого устройства | Не все уважают `ExcludeClipboardContentFromMonitorProcessing` | Текст до 256 КиБ и так приходит вместе с предложением; изображения ждут вставки |
| Windows | После выхода `bridged` содержимое, скопированное на другом устройстве, пропадает из буфера | При `WM_RENDERALLFORMATS` пришлось бы скачать всё по сети | Осознанный выбор; локальные копии не затрагиваются |
| Все | Копирование файлов через буфер пока не работает | Формат FILES обслуживает движок файлов | Веха 6a |
| macOS | Буфер обмена не реализован | Владелец перенёс все работы по macOS в конец этапа (нет техники Apple) | `Unsupported`; пункт «macOS» в ROADMAP |
| Linux | MIDI зависит от системной `libasound` (LGPL-2.1) | Виртуальные порты ALSA sequencer | Динамическая связь с системной библиотекой (ADR-0013); запасной путь — прямые ioctl |
| Android 10+ | Буфер читается только приложением в фокусе | Политика приватности Android | Синхронизация при открытии, по кнопке, из плитки быстрых настроек |
| Android 12+ | Система показывает тост при чтении буфера | Политика Android | Читаем только по действию пользователя |
| Android | Телефон не может быть управляемым устройством (курсор на телефоне) | Нужен AccessibilityService | ROADMAP |
| Все | mDNS не работает в сетях с изоляцией клиентов (часто — университетский и гостевой Wi-Fi) и между подсетями | Multicast блокируется точкой доступа | Ручное добавление по IP (`bridge pair <IP:PORT> <код>`), QR-ссылка с адресом; адрес запоминается в `trust.toml` |
| Windows | При первом запуске `bridged` на `0.0.0.0` Защитник Windows спрашивает разрешение на входящие подключения | Политика брандмауэра для новых программ | Установщик добавит правило (веха 9/11); до этого — подтвердить вручную для частных сетей |
| Все | Профили сетей не используют SSID по умолчанию | SSID требует разрешения геолокации на Win 11 24H2+, macOS 14+, Android | Отпечаток по MAC шлюза (ADR-0016) |
