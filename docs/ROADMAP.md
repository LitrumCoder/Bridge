# Bridge — дорожная карта

## Этап 1: вехи

Каждая веха = код + тесты + зелёный CI + коммит. Веха не закрывается, пока её пункты в
[MANUAL_TESTS.md](MANUAL_TESTS.md) не описаны (выполнить их может только владелец на реальных устройствах).

## Точки расширения под будущее

| Будущая функция | Точка расширения на этапе 1 |
|---|---|
| Bluetooth LE, Wi-Fi Direct, кабель, relay | `Transport` + `TransportCaps`; модули `transport/{ble,wifi_direct,cable,relay}.rs` с `TODO`; `Discovery` отделён от транспорта |
| Автовыбор канала и бесшовное переключение | `ChannelScheduler` (класс канала → транспорт), `PeerSession` отделён от соединения, `session_id` и `resume` в `ClientHello` |
| Звук между устройствами, «звук за курсором» | Класс канала `RealtimeMedia` (datagrams с FeatureId), событие «курсор перешёл на устройство» уже публикуется фичам |
| Автопереключение Bluetooth-наушников | То же событие + трейт платформы (новый) |
| Wake-on-LAN | MAC-адреса интерфейсов пира сохраняются в хранилище доверия с этапа 1 |
| Телефон как второй экран | Экран без физического устройства в `ScreenInfo` (виртуальный экран), геометрия уже не привязана к ОС |
| Проброс периферии, уведомления и звонки, история буфера, Ableton Link, Stream Deck, проброс портов, GPU, автоматизация | Новые фичи за трейтом `Feature`, свои `FeatureId` и `PermissionId` |
| Плагины и API | Диапазон `FeatureId ≥ 32768`, IPC-API демона версионирован |
| Гостевой режим по QR | Права — открытый набор, в записи доверия есть срок действия (`expires_at`) |
| Веб-клиент WebRTC | Ещё одна реализация `Transport` |
| Курсор на Android через Accessibility | `InputInjector` для Android (сейчас отсутствует — явно) |
| Синхронизация папок, поиск по устройствам | Движок файлов с докачкой и хешами — основа |
| Команды на естественном языке | IPC-API демона |

## Перенесено в конец этапа: macOS

Владелец попросил закончить всё по macOS в последнюю очередь: у него нет техники Apple, проверить нечем.
Ввод (веха 4c) уже написан и собирается. Остальное (`TODO(macOS-final)`):

- буфер обмена (`NSPasteboard`, опрос `changeCount`, data provider, `org.nspasteboard.ConcealedType`);
- перетаскивание (file promises), виртуальные MIDI-порты CoreMIDI, `NetworkMonitor`;
- синхронизация раскладки (Text Input Sources), Caps Lock через IOKit;
- сборка Tauri-приложения и подпись/нотаризация.
