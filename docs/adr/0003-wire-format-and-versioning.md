# ADR-0003. Формат сообщений и версионирование

Статус: Предложено

## Контекст

Нужна компактная бинарная сериализация (движения мыши — тысячи сообщений в секунду, datagram ~12 байт),
явная проверка совместимости версий, устойчивость к произвольным байтам от недоверенных пиров и возможность
добавлять функции без изменения ядра.

## Решение

- **postcard 1.x** поверх serde: varint-кодирование, задокументированный стабильный формат,
  `no_std`-совместим. bincode отвергнут: RUSTSEC-2025-0141, проект прекращён.
- Конверт `Envelope { feature: FeatureId(u16), kind: u16, payload }`; ядро маршрутизирует, не разбирая payload.
- Кадры потоков: varint-длина, проверка лимита класса канала **до** выделения буфера.
- Лимиты декодера: максимальные длины `Vec`/`String` задаются типами-обёртками (`BoundedVec<T, N>`,
  `BoundedString<N>`), которые проверяют длину при десериализации. Рекурсивных типов в протоколе нет.
- `PROTOCOL_VERSION = (major, minor)`. Major — конверт и рукопожатие; minor — добавления.
- Каждая фича: `FeatureDescriptor { id, versions: RangeInclusive<u16> }`; при рукопожатии выбирается
  максимальная общая версия, без пересечения фича выключается для этого пира.
- **Опубликованные структуры не меняются.** Новое поле = новый `kind` или новая версия фичи. Файл
  `crates/protocol/tests/golden/*.bin` хранит эталонные байты каждого сообщения; тест падает при случайном
  изменении формата.
- Datagram: `[формат u8][FeatureId varint][payload]`.

## Альтернативы

- **Protocol Buffers (prost).** Самоописывающая эволюция полей, но лишняя кодогенерация, больше байт на
  маленьких сообщениях; ценность эволюции полей меньше, чем дисциплина «новый kind».
- **Cap'n Proto / FlatBuffers.** Zero-copy не нужен на таких размерах, API сложнее, хуже fuzz-ергономика.
- **bitcode / wincode / rkyv.** Нет стабильного задокументированного формата или моложе postcard.

## Последствия

- Golden-тесты защищают совместимость.
- Fuzz-цель на `Envelope::decode` и на декодер каждой фичи.
- Отказ от postcard в будущем возможен через major-версию.
