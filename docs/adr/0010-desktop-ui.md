# ADR-0010. Десктоп-UI: Tauri 2 + Svelte 5

Статус: Предложено

## Контекст

UI — трей, разделы (устройства и сопряжение, раскладка экранов, файлы, MIDI, сеть, журнал, настройки),
светлая/тёмная тема, ru/en. Закрытие UI не останавливает демон. Стек задан: Tauri 2 + TypeScript,
фреймворк — на выбор.

## Решение

- **Tauri 2.12** (трей в ядре за feature `tray-icon`), плагины стабильной ветки 2.x: `single-instance`,
  `autostart`, `notification`, `dialog`. Ветка плагинов 3.0.0-alpha не используется.
- **Svelte 5** (руны) + TypeScript + Vite.
  - Почему не React: больше рантайм, больше шаблонного кода для частых обновлений метрик (задержка,
    джиттер, прогресс), без выигрыша для небольшой программы.
  - Почему не SolidJS: схожая реактивность, но меньше экосистема компонентного тестирования; Svelte 5
    компилируется в маленький бандл и имеет зрелый `@testing-library/svelte`.
- Rust-часть Tauri — только IPC-клиент демона (`crates/ipc`) и трей; бизнес-логики в UI нет.
- Редактор раскладки — SVG с перетаскиванием блоков устройств, прилипанием краёв, масштабом в мм.
- Локализация: свой типизированный словарь (`ru.ts`, `en.ts` с проверкой ключей компилятором TypeScript) —
  без зависимости; `paraglide-js` рассматривался, но избыточен для двух языков.
- Тема: CSS-переменные, следование системной теме + ручной выбор.
- Тесты: Vitest + `@testing-library/svelte` (компоненты), Playwright против Vite-сборки с подменой Tauri IPC
  через `@tauri-apps/api/mocks` (все ОС), WebDriver + `tauri-driver` на Linux/Windows для e2e настоящего приложения.

## Последствия

- Трей живёт в UI-процессе: он автозапускается вместе с демоном, а «Выйти» в трее закрывает только UI.
- На macOS `tauri-driver` недоступен — e2e там только через Playwright с mock IPC.
