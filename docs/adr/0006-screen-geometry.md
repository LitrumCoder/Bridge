# ADR-0006. Геометрия раскладки экранов

Статус: Предложено

## Контекст

У устройств по несколько мониторов с разными разрешениями, масштабом и физическими размерами. Переход через
край не должен давать скачок по высоте, скорость курсора должна быть физически одинаковой, обратный переход
должен возвращать в исходную точку.

## Решение

- Модель экрана: пиксели, положение в виртуальном столе устройства, масштаб ОС, физический размер в мм
  (EDID; если недоступен — из DPI, а пользователь может поправить в редакторе).
- Общая раскладка хранит прямоугольник каждого экрана в **мм** (f64). В редакторе устройство перемещается блоком,
  сохраняя взаимное расположение своих экранов; тонкая подстройка отдельных экранов — опция.
- Переходы **внутри устройства** — по его пиксельной раскладке (как делает ОС), **между устройствами** — по мм.
- Виртуальный курсор хранит дробную позицию; округление только при инъекции. Отсюда точный обратный переход.
- Перевод смещения: `Δpx_dst = Δpx_src · ppmm_dst / ppmm_src`.
- Смежность: края экранов разных устройств, совпадающие после «прилипания» (допуск 2 мм) и перекрывающиеся
  по длине. Для общего отрезка края точка выхода переводится в мм, затем в пиксели входа.
- Отсутствующие устройства: край к ним — стена; если за ними по направлению есть присутствующий экран,
  переход пробрасывается к нему с сохранением перпендикулярной координаты в мм (схлопывание без изменения
  сохранённой раскладки).
- Версия раскладки: Lamport-счётчик + `device_id`; при подключении пиры сравнивают дайджест и при расхождении
  передают раскладку целиком.
- Все вычисления с проверкой конечности (NaN/∞ от пира → отказ), координаты из сети ограничены ±10⁶ мм.

## Альтернативы

- **Пиксели виртуального стола без учёта DPI** (как многие KVM-программы). Скачки на мониторах с разной плотностью.
- **Нормализованные координаты 0…65535 на устройство** (подход Mouse Without Borders). Просто, но
  физическая непрерывность края теряется.

## Последствия

Property-тесты: обход «край → обратно» для произвольных раскладок, монотонность и непрерывность вдоль края,
отсутствие паник на произвольных числах.
