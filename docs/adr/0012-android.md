# ADR-0012. Android

Статус: Принято 2026-10-26 — вариант 1 (UniFFI), MPL-2.0 для немодифицированных crates разрешена ADR-0013.

## Контекст

Android 10+: обнаружение и сопряжение по QR, отправка через «Поделиться», приём в выбранную папку, буфер с учётом
ограничений, тачпад/клавиатура, работа в фоне. Стек задан: Kotlin + Jetpack Compose, ядро на Rust через UniFFI.

## Проблема

**UniFFI распространяется под MPL-2.0** — эта лицензия не входит в разрешённый список (MIT/Apache-2.0/BSD/ISC/Zlib).
MPL-2.0 — слабый копилефт на уровне файлов: при использовании без изменений обязательство сводится к доступности
исходников самих MPL-файлов (они и так публичны), собственный код не заражается. Сгенерированный Kotlin-код
строится из MPL-шаблонов UniFFI, поэтому его статус тоже стоит считать MPL.

## Варианты

1. **Разрешить MPL-2.0 точечно для `uniffi*`** (исключение в `deny.toml` с обоснованием). Быстро, генерация
   биндингов, async → `suspend`, Kotlin-колбэки через foreign traits.
2. **Ручной JNI через crate `jni` (MIT/Apache).** Небольшая поверхность API (≈15 функций: старт/стоп узла,
   список устройств, сопряжение, отправка файла, события, буфер, тачпад) — реально написать вручную.
   Плюс: никаких исключений из политики. Минус: ручная работа с потоками JNI и колбэками.

**Рекомендация** связана с ADR-0013. MPL-2.0 почти наверняка всё равно придётся разрешить для немодифицированных
crates (транзитивно через `directories` и Tauri). Если это правило принято — вариант 1, UniFFI, как в ТЗ.
Если владелец выбирает строгий запрет MPL — вариант 2: поверхность маленькая, мост тестируется так же
(инструментальный тест вызова Rust из Kotlin).

## Решение (общее для обоих вариантов)

- Rust-узел `bridge_node` в `crates/ffi`, собирается `cargo-ndk` для `arm64-v8a`, `armeabi-v7a`, `x86_64`.
- Foreground Service с типом **`connectedDevice`** (Android 14+ требует тип; `dataSync` на Android 15 ограничен
  6 ч в сутки — не подходит для постоянного соединения).
- Обнаружение: mDNS из Rust (`mdns-sd`) с `WifiManager.MulticastLock`; `NsdManager` — запасной вариант.
- Буфер: Android 10+ разрешает чтение только приложению в фокусе (или IME) — синхронизация при открытии
  приложения, по кнопке и через плитку быстрых настроек (открывает прозрачную Activity на мгновение).
- Приём файлов: папка через `ACTION_OPEN_DOCUMENT_TREE` (SAF) с сохранением разрешения.
- Отправка: `ACTION_SEND`/`ACTION_SEND_MULTIPLE` → выбор устройства.
- Тачпад: Compose-поверхность → относительные смещения, двухпальцевая прокрутка, тап = клик, клавиатура.
- Тесты: JUnit для ViewModel, Compose UI-тесты на эмуляторе в CI, инструментальный тест моста.
