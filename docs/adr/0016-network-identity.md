# ADR-0016. Отпечаток сети для профилей

Статус: Предложено

## Контекст

Нужны автовыход при смене Wi-Fi-сети, автовозврат в известной сети и профили (дом / университет).
Получение SSID требует разрешения геолокации на Windows 11 24H2+, macOS 14+ и Android — просить геолокацию
у программы для клавиатуры и мыши странно.

## Решение

- Отпечаток сети = SHA-256 от (MAC шлюза по умолчанию, префикс подсети) для каждого активного интерфейса
  с маршрутом по умолчанию. MAC шлюза берётся из ARP/neighbor-таблицы (`GetIpNetTable2`, `sysctl NET_RT_FLAGS`,
  netlink `RTM_GETNEIGH`) — без особых разрешений.
- SSID добавляется в отображаемое имя профиля, если ОС отдаёт его без запроса разрешений.
- `NetworkMonitor` сообщает о смене маршрута по умолчанию; `core` с дебаунсом 3 с решает: неизвестная сеть →
  `Left(NetworkChanged)`, известная с `auto_join` → `Rejoin`.
- Пользователь может «запомнить текущую сеть как профиль» и переименовать её.

## Альтернативы

SSID/BSSID — нужны разрешения геолокации; публичный IP — нужен внешний сервис, меняется у провайдера.

## Последствия

Ограничения: несколько сетей за одним роутером с одинаковым шлюзом (гостевая сеть с тем же MAC) неразличимы;
mesh-системы иногда меняют MAC шлюза — профиль хранит несколько отпечатков.
