# ADR-0016. Отпечаток сети для профилей

Статус: Принято (веха 8)

## Контекст

Нужны автовыход при смене Wi-Fi-сети, автовозврат в известной сети и профили (дом / университет).
Получение SSID требует разрешения геолокации на Windows 11 24H2+, macOS 14+ и Android — просить геолокацию
у программы для клавиатуры и мыши странно.

## Решение

- Отпечаток сети = SHA-256 от (MAC шлюза по умолчанию, префикс подсети) для каждого активного интерфейса
  с маршрутом по умолчанию. MAC шлюза берётся из ARP/neighbor-таблицы (`GetIpNetTable2`, `sysctl NET_RT_FLAGS`,
  netlink `RTM_GETNEIGH`) — без особых разрешений.
- SSID добавляется в отображаемое имя профиля, если ОС отдаёт его без запроса разрешений.
- `NetworkMonitor` сообщает о смене маршрута по умолчанию; `core` с дебаунсом 3 с решает: неизвестная сеть →
  `Left(NetworkChanged)`, известная с `auto_join` → `Rejoin`.
- Пользователь может «запомнить текущую сеть как профиль» и переименовать её.

## Реализация (веха 8)

- `bridge_platform::network::current_network()` возвращает шлюз по умолчанию, его MAC (если есть в ARP),
  подсеть и длину префикса.
  - Linux: `/proc/net/route` (маршрут `0.0.0.0/0` с наименьшей метрикой) и `/proc/net/arp`.
  - Windows: `GetBestRoute`, `GetIpNetTable`, `GetIpAddrTable` — без запросов и без разрешений.
  - macOS — в конце этапа.
- Демон раз в 2 с считает отпечаток `SHA-256(MAC шлюза или его адрес ‖ подсеть ‖ префикс)` и передаёт его в
  `DeviceStateMachine` (`bridge_core::state`).
- Автомат ждёт 3 с стабильности. Если сеть неизвестна, устройство выходит из группы с причиной
  `NETWORK_CHANGED`. Если сеть известна и у профиля `auto_join`, устройство возвращается — но только после
  выхода по сети. Ручной `leave` сетью не отменяется.
- **Пока профилей нет, ничего автоматического не происходит**: иначе первая же смена Wi-Fi выводила бы
  устройство из группы.
- Профили лежат в `<data>/profiles.toml` (`[[profile]] name, auto_join, networks = [base32]`). Одна сеть
  принадлежит одному профилю, у профиля может быть несколько сетей (mesh).
- Команды: `bridge profile save <имя> [--auto-join]`, `bridge profile forget <имя>`, `bridge profiles`.
- SSID не читается совсем (`TODO(M9)`: показывать, где ОС отдаёт его без разрешений).

## Альтернативы

SSID/BSSID — нужны разрешения геолокации; публичный IP — нужен внешний сервис, меняется у провайдера.

## Последствия

Ограничения: несколько сетей за одним роутером с одинаковым шлюзом (гостевая сеть с тем же MAC) неразличимы;
mesh-системы иногда меняют MAC шлюза — профиль хранит несколько отпечатков.
